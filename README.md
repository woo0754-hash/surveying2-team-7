예제 재현 안내는 [학생 사용 안내](STUDENT_GUIDE.md)를 참고하세요. Python 의존성은 `requirements.txt`에 있습니다. GEE 분석에는 실행자 자신의 계정 인증과 프로젝트 설정이 필요합니다.
